# Expense Snap — receipt logger with CSV export

A single-file installable PWA (index.html inline CSS/JS, manifest.json, sw.js): log an expense in under five seconds (amount, category, note, optional receipt photo captured via file input and downscaled on canvas), stored in IndexedDB; monthly totals by category, a simple bar summary drawn on canvas, edit/delete entries, and one-tap export of any month as CSV. No server, no accounts, fully offline. The deliverable is the complete index.html, manifest.json, and sw.js source.
